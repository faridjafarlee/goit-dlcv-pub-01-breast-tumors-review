# Наукова публікація 1: рев'ю статті про пухлини молочної залози

Здавати:
- посилання на Google Doc з назвою `Джафарлі. Рев’ю ВИЯВЛЕННЯ ТА КЛАСИФІКАЦІЯ`;
- PDF `Джафарлі. Рев’ю ВИЯВЛЕННЯ ТА КЛАСИФІКАЦІЯ.pdf` (1 сторінка).

Як зробити Google Doc: завантажити `.docx` на Google Drive, відкрити через Google Документи, перейменувати як вище і дати доступ "Усі, хто має посилання".

Обсяг: 431 слово основного тексту, 459 разом із назвою, рядком автора і заголовками (умова: від 300 до 500). Структура з 5 розділів, як в умові.

Факти звірені з текстом статті (`../materials/pub1_original.txt`). Перед здачею варто перечитати текст і за потреби переписати окремі речення своїми словами.

Інші файли: `content.js` (текст рев'ю), `build_docx.js` і `build_html.js` (збірка .docx і `review.html`, з якого друкується PDF).

Перезбірка:

```bash
NODE_PATH=<node_modules з пакетом docx> node build_docx.js
node build_html.js
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --no-pdf-header-footer \
  --print-to-pdf="$PWD/Джафарлі. Рев’ю ВИЯВЛЕННЯ ТА КЛАСИФІКАЦІЯ.pdf" "file://$PWD/review.html"
```
